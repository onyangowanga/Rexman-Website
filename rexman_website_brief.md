# Rexman Engineering Services Limited Website Brief

## Project Objective

Create a simple, professional, corporate landing page for **Rexman Engineering Services Limited** using the domain **www.rexman.co.ke**. The website is intended as a temporary but highly professional online presence while the full company profile and project portfolio are being finalized.

The website should immediately communicate credibility, professionalism, construction expertise, and engineering capability.

# Website Strategy

## Phase 1 (Current)

Develop a professional one-page website / landing page.

Purpose:

- Establish digital presence
- Support business cards
- Support company profile distribution
- Provide contact information
- Build trust with potential clients
- Showcase key services and selected projects

The website should be modern, fast, mobile-friendly, and visually professional.
